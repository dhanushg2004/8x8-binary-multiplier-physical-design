🚀 **Completed an RTL-to-GDSII Physical Design Project!**

I completed the physical design flow of an **8×8 Binary Multiplier** using open-source ASIC design tools.

🔹 RTL: Verilog  
🔹 Synthesis: Yosys  
🔹 PDK: SKY130A  
🔹 Flow: OpenLane / OpenROAD  
🔹 Layout: Magic + KLayout  
🔹 Analysis: SPEF + Static Timing Analysis  
🔹 Verification: DRC, LVS, Antenna and ERC  

I also performed a **floorplan utilization experiment**, comparing 30% and 50% core utilization to study the effect on area, routing and timing.

Final signoff timing:
- WNS: 0.00 ns
- TNS: 0.00 ns
- Worst setup slack: +1.78 ns
- Worst hold slack: +4.41 ns

This project helped me gain practical exposure to the complete **RTL → Synthesis → Floorplan → Placement → Routing → STA → DRC/LVS → GDSII** flow.
