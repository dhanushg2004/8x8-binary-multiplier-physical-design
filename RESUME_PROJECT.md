## 8×8 Binary Multiplier — RTL to GDSII Physical Design

- Implemented an 8×8 combinational binary multiplier in Verilog and synthesized it using Yosys with the SKY130A standard-cell library.
- Executed an RTL-to-GDSII physical-design flow using OpenLane/OpenROAD, covering floorplanning, PDN, placement, routing, parasitic extraction, STA and physical verification.
- Performed 30% vs 50% core-utilization analysis and evaluated changes in core/die area, routing resources and timing.
- Completed DRC, LVS, antenna/ERC checks and generated final GDSII; final signoff reported **+1.78 ns setup slack** and **+4.41 ns hold slack**.
